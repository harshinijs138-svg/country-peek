# CountryPeek

CountryPeek is a React application for searching and exploring countries using the RestCountries API.

## Features

- Search countries by name
- Filter by region
- Sort by name and population
- Country detail page
- Dark and light theme
- Save favourites with localStorage
- Responsive mobile design

## Tech Stack

- React
- Vite
- React Router DOM
- Context API
- useReducer
- CSS Variables
- RestCountries API
